# 开发计划

中文 | [English](roadmap_en.md)

- [X] 提供 Clash Verge Rev 一键接入，支持全局／规则模式及订阅跟随。
- [ ] 完善独立的复旦校园代理（SOCKS5／HTTP），与 Clash 协同方式共用登录和校园规则。
- [ ] 首页连接卡增加“配合 Clash／独立使用”切换，默认配合 Clash；断开后可切换并记住选择，设置按当前方式展示。
- [X] 完善升级与目录迁移，处理旧配置冲突，支持移除 FDU 接入。
- [X] 增加校内网址自检，检查规则命中及通过 Clash 的访问结果。
- [X] 验证并完善断网、网络切换和休眠唤醒后的连接恢复。
- [X] 验证并完善 Clash 异常退出、控制接口失联后的 FDU 退出与接入恢复。
- [X] 完善登录过期处理，提供重新登录入口。
- [X] 支持校内规则导入／导出。
- [X] 实机验证并完善 FlClash、Clash Party 桌面版的通用接入。
- [X] 实机验证并完善 Sparkle、Clash Nyanpasu、ClashX.Meta 的通用接入。
- [ ] 公布按客户端版本和操作系统验证的兼容列表。
- [X] 支持输入校园网址一键诊断，展示规则命中、代理覆盖、登录与隧道状态及 DNS／TLS／HTTP 结果，区分预期路径与实测证据，并给出可执行的处理建议。
- [ ] 完善启动、切网、唤醒和异常退出后的恢复，等待 Clash 就绪后自动接入，复核连接并处理 Clash 重启和未完成的恢复记录；验证停用 FDU 后外网仍可正常使用。
- [ ] 增加可跳过、可重新打开的首页首次使用引导，完成客户端确认、UIS 登录和访问验证，沿用内置校园规则。
- [ ] 完善托盘状态与快捷操作，提供重新登录、打开诊断入口；需要用户操作时仅提醒一次。
- [X] 支持预览、复制和导出脱敏诊断报告，包含版本、接入方式、规则状态和检测结果，隐藏账号、Token、Cookie 及个人内网信息。
